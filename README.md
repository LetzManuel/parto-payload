# Parto Payload

Check, fix and build Coupa CSV import files. Works offline.

**Open the app:** https://payload.parto.at/ and install it from the browser (Edge or Chrome: install icon in the address bar; iPhone: Share > Add to Home Screen; Android: ⋮ > Install app).

This repository holds only the built app files. It contains no customer data, secrets or settings: all data stays in the user's browser and, if they sign in, in their own OneDrive.

**Offline single file:** [offline/parto-payload-offline.html](offline/parto-payload-offline.html). Download it and open it from disk. It works without any server; cloud sync is available only in the installed app.
